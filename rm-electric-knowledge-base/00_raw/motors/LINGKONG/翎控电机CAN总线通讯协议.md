## 一、CAN 总线参数

| 参数 | 说明 |
|------|------|
| 总线接口 | CAN |
| 波特率（常规模式） | 1Mbps（默认）、500kbps、250kbps、125kbps、100kbps |
| 波特率（广播模式） | 1Mbps、500kbps |
| 最大挂载数量 | 最多 32 个驱动（视总线负载情况） |
| 帧格式 | 数据帧 |
| 帧类型 | 标准帧 |
| DLC | 8 字节 |

### 报文标识符

| 方向 | 标识符 |
|------|--------|
| 主机 → 电机（命令） | `0x140 + ID`（ID 范围 1~32） |
| 电机 → 主机（回复） | `0x180 + ID`（ID 范围 1~32） |

电机在收到命令后 0.25ms 内向主机发送回复。

## 三、控制方式分类

### 3.1 基本状态控制

#### 电机运行 (`0x88`)
- 将电机从关闭状态切换到开启状态
- LED 由慢闪转为常亮
- 之后发送控制指令即可控制电机动作

#### 电机关闭 (`0x80`)
- 将电机从开启状态切换到关闭状态
- 清除电机转动圈数及之前接收的控制指令
- LED 由常亮转为慢闪
- 电机仍可回复控制命令，但不执行动作

#### 电机停止 (`0x81`)
- 停止电机，但**不清除**电机运行状态
- 再次发送控制指令即可继续控制电机动作

### 3.2 开环控制 (`0xA0`)
- **仅 MS 电机**支持
- 控制值：`powerControl`（int16_t，范围 -850 ~ 850）
- 控制输出到电机的开环电压
- 不受上位机 Max Power 限制
- 回复数据与"读取电机状态2"相同

### 3.3 转矩闭环控制 (`0xA1`)
- **仅 MF、MH、MG 电机**支持
- 控制值：`iqControl`（int16_t，范围 -2048 ~ 2048）
- MF 电机实际转矩电流：-16.5A ~ 16.5A
- MG 电机实际转矩电流：-33A ~ 33A
- 不受上位机 Max Torque Current 限制
- 回复数据与"读取电机状态2"相同

### 3.4 速度闭环控制

#### 速度闭环控制 (`0xA2`)
- 控制值：
  - `speedControl`（int32_t，单位 0.01 dps/LSB）
  - `iqControl`（int16_t，范围 -2048 ~ 2048，力矩限制）
- 受上位机 Max Speed 限制
- 受上位机 Max Acceleration 限制
- 回复数据与"读取电机状态2"相同

### 3.5 位置闭环控制（多圈）

#### 多圈位置闭环控制1 (`0xA3`)
- `angleControl`（int32_t，单位 0.01°/LSB，36000 = 360°）
- 转动方向由目标位置与当前位置的差值决定
- 受上位机 Max Angle、Max Speed、Max Acceleration 限制
- MF/MH/MG 受 Max Torque Current 限制；MS 受 Max Power 限制

#### 多圈位置闭环控制2 (`0xA4`)
- 比命令1 多了 `maxSpeed` 参数（uint16_t，单位 1 dps/LSB）
- 可指定本次运动的最大速度
- 其他限制同命令1

### 3.6 位置闭环控制（单圈）

#### 单圈位置闭环控制1 (`0xA5`)
- `spinDirection`（uint8_t）：`0x00` = 顺时针，`0x01` = 逆时针
- `angleControl`（uint32_t，单位 0.01°/LSB）
- 受 Max Speed、Max Acceleration、Max Torque Current/Max Power 限制

#### 单圈位置闭环控制2 (`0xA6`)
- 比命令1 多了 `maxSpeed` 参数（uint16_t，单位 1 dps/LSB）
- 其他同命令1

### 3.7 位置闭环控制（增量）

#### 增量位置闭环控制1 (`0xA7`)
- `angleIncrement`（int32_t，单位 0.01°/LSB）
- 转动方向由参数符号决定（正=顺时针，负=逆时针）
- 受 Max Speed、Max Acceleration、Max Torque Current/Max Power 限制

#### 增量位置闭环控制2 (`0xA8`)
- 比命令1 多了 `maxSpeed` 参数（uint16_t，单位 1 dps/LSB）
- 其他同命令1

## 四、状态读取命令详解

### 4.1 读取电机状态1和错误标志 (`0x9A`)

回复数据包含：

| 字节 | 内容 | 类型 | 说明 |
|------|------|------|------|
| DATA[0] | 命令字节 | uint8_t | `0x9A` |
| DATA[1] | 电机温度 | int8_t | 单位 1℃/LSB |
| DATA[2] | 母线电压低字节 | int16_t | 单位 0.01V/LSB |
| DATA[3] | 母线电压高字节 | | |
| DATA[4] | 母线电流低字节 | int16_t | 单位 0.01A/LSB |
| DATA[5] | 母线电流高字节 | | |
| DATA[6] | 电机状态 | uint8_t | `0x00`=开启，`0x10`=关闭 |
| DATA[7] | 错误标志 | uint8_t | 见下方错误标志表 |

#### 错误标志位 (errorState)

| 位 | 状态说明 | 0 | 1 |
|----|----------|---|---|
| 0 | 低电压状态 | 正常 | 低压保护 |
| 1 | 高电压状态 | 正常 | 高压保护 |
| 2 | 驱动温度状态 | 正常 | 驱动过温 |
| 3 | 电机温度状态 | 正常 | 电机过温 |
| 4 | 电机电流状态 | 正常 | 电机过流 |
| 5 | 电机短路状态 | 正常 | 电机短路 |
| 6 | 堵转状态 | 正常 | 电机堵转 |
| 7 | 输入信号状态 | 正常 | 输入信号丢失超时 |

### 4.2 读取电机状态2 (`0x9C`)

回复数据包含：

| 字节 | 内容 | 类型 | 说明 |
|------|------|------|------|
| DATA[0] | 命令字节 | uint8_t | `0x9C` |
| DATA[1] | 电机温度 | int8_t | 单位 1℃/LSB |
| DATA[2-3] | 转矩电流 iq / 输出功率 | int16_t | 见下方说明 |
| DATA[4-5] | 电机转速 | int16_t | 单位 1 dps/LSB |
| DATA[6-7] | 编码器位置 | uint16_t | 14bit: 0~16383, 15bit: 0~32767, 16bit: 0~65535 |

- MF/MH/MG 电机：DATA[2-3] 为转矩电流 iq
  - MG：分辨率 (66/4096) A/LSB
  - MF：分辨率 (33/4096) A/LSB
- MS 电机：DATA[2-3] 为输出功率 power，范围 -1000 ~ 1000

### 4.3 读取电机状态3 (`0x9D`)
- **MS 电机不支持**
- 读取三相电流数据

回复数据：

| 字节 | 内容 | 类型 | 说明 |
|------|------|------|------|
| DATA[0] | 命令字节 | uint8_t | `0x9D` |
| DATA[1] | 电机温度 | int8_t | 1℃/LSB |
| DATA[2-3] | A相电流 iA | int16_t | MG: (66/4096)A/LSB, MF: (33/4096)A/LSB |
| DATA[4-5] | B相电流 iB | int16_t | 同上 |
| DATA[6-7] | C相电流 iC | int16_t | 同上 |

## 五、辅助功能命令

### 5.1 抱闸器控制和状态读取 (`0x8C`)

**发送：**

| 字节 | 内容 |
|------|------|
| DATA[0] | `0x8C` |
| DATA[1] | `0x00`=抱闸器断电（刹车启动），`0x01`=抱闸器通电（刹车释放），`0x10`=读取状态 |
| DATA[2-7] | `0x00` |

**回复：**

| 字节 | 内容 |
|------|------|
| DATA[0] | `0x8C` |
| DATA[1] | `0x00`=抱闸器断电/刹车启动，`0x01`=抱闸器通电/刹车释放 |

### 5.2 读取编码器数据 (`0x90`)

回复数据：

| 字节 | 内容 | 类型 |
|------|------|------|
| DATA[0] | `0x90` | |
| DATA[2-3] | 编码器位置（原始-零偏） | uint16_t |
| DATA[4-5] | 编码器原始位置 | uint16_t |
| DATA[6-7] | 编码器零偏 | uint16_t |

### 5.3 设置当前位置到ROM作为电机零点 (`0x19`)

- 将当前编码器原始值写入 ROM 作为零点
- **需要重新上电才能生效**
- 写入 ROM，多次写入会影响芯片寿命，不建议频繁使用
- 回复中包含 `encoderOffset`（uint16_t）

### 5.4 读取多圈角度 (`0x92`)

回复数据：

| 字节 | 内容 | 类型 | 说明 |
|------|------|------|------|
| DATA[0] | `0x92` | | |
| DATA[1-7] | 多圈角度 | int64_t（低7字节） | 0.01°/LSB，正=顺时针累计，负=逆时针累计 |

### 5.5 读取单圈角度 (`0x94`)

回复数据：

| 字节 | 内容 | 类型 | 说明 |
|------|------|------|------|
| DATA[0] | `0x94` | | |
| DATA[4-7] | 单圈角度 | uint32_t | 0.01°/LSB，范围 0 ~ 36000×减速比-1，顺时针增加 |

### 5.6 设置当前位置为任意角度 (`0x95`)

- 写入 RAM，即时生效，断电失效
- `motorAngle`（int32_t，单位 0.01°/LSB）

## 六、参数读写命令

### 6.1 读取控制参数 (`0xC0`)

| 字节 | 内容 |
|------|------|
| DATA[0] | `0xC0` |
| DATA[1] | 参数序号 controlParamID |
| DATA[2-7] | `0x00` |

回复中 DATA[2-7] 为参数值（6字节）。

### 6.2 写入控制参数 (`0xC1`)

| 字节 | 内容 |
|------|------|
| DATA[0] | `0xC1` |
| DATA[1] | 参数序号 controlParamID |
| DATA[2-7] | 参数值（6字节） |

- 写入 RAM，即时生效，**断电失效**
- 回复包含写入后的参数值

## 七、电机控制参数表

### PID 参数

| 序号 (ParamID) | 参数 | 字节布局 |
|----------------|------|----------|
| `0x0A` | **角度环 PID** | Byte1-2: anglePidKp (uint16_t) |
| | | Byte3-4: anglePidKi (uint16_t) |
| | | Byte5-6: anglePidKd (uint16_t) |
| `0x0B` | **速度环 PID** | Byte1-2: speedPidKp (uint16_t) |
| | | Byte3-4: speedPidKi (uint16_t) |
| | | Byte5-6: speedPidKd (uint16_t) |
| `0x0C` | **电流环 PID** | Byte1-2: currentPidKp (uint16_t) |
| | | Byte3-4: currentPidKi (uint16_t) |
| | | Byte5-6: currentPidKd (uint16_t) |

### 限制参数

| 序号 (ParamID) | 参数 | 类型 | 说明 |
|----------------|------|------|------|
| `0x1E` | inputTorqueLimit | int16_t | 最大力矩电流 |
| `0x20` | inputSpeedLimit | int32_t | 最大速度 |
| `0x22` | inputAngleLimit | int32_t | 角度限制 |
| `0x24` | inputCurrentRamp | int32_t | 电流斜率 |
| `0x26` | inputSpeedRamp | int32_t | 速度斜率 |

## 八、错误状态恢复

- 清除错误标志命令：`0x9B`
- **注意**：电机状态没有恢复正常时，错误标志无法清除
- 回复数据与"读取电机状态1和错误标志"相同（仅命令字节改为 `0x9B`）

| 特性 | MF | MH | MG | MS |
|------|----|----|----|----|
